# Skillهای پروژه

ده Skill طبق سند در `.agents/skills/` نگهداری می‌شوند: برند/UX، فارسی/RTL، storefront، admin، commerce، Iran payments، auth/security، ops، QA، SEO/performance. تمام نام‌ها پیشوند `morphiume-` دارند؛ فایل‌ها دستور پروژه‌اند و secret ندارند.

پوشهٔ کشف استاندارد مطابق مستندات رسمی Codex است. این جلسه از `S:\` آغاز شده؛ خواندن مستقیم Skillهای پروژه و validation واقعاً انجام می‌شود. حضور در فهرست خودکار UI همین جلسه تا مشاهدهٔ صریح ادعا نمی‌شود؛ Codex باید از ریشهٔ مخزن اجرا شود تا scope استاندارد برقرار باشد.

Skillهای موجودِ استفاده‌شده بدون نصب تازه: OpenAI Docs و skill-creator از bundle OpenAI، ui-ux-pro-max از مسیر محلی، find-docs/context7-cli برای docs و playwright-cli برای آزمون مرورگر. منبع فایل و وضعیت استفاده در گزارش عامل‌ها ثبت می‌شود. هیچ Skill دانلودی ناشناخته نصب نمی‌شود.

اعتبار YAML و نام با `pnpm skills:validate` و validator رسمی skill-creator بررسی می‌شود؛ این آزمون ساختاری، کیفیت رفتار یا auto activation را ثابت نمی‌کند.
