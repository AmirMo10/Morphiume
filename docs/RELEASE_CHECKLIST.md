# شرط‌های انتشار و نتیجهٔ موجود

| شرط | وضعیت مشاهده‌شده |
|---|---|
| مشخصات، نقش‌های واقعی و ده Skill | فاز صفر در b01c09f روی main؛ validator رسمی موفق |
| ساخت یکپارچه، نوع و lint | production build مستقل و TypeScript/ESLint موفق؛ native Sharp DLL omission در smoke یافت و اصلاح شد؛ چهار regression خرید/عمومی روی خروجی تازه موفق شدند |
| مالی/انبار/OTP/MFA | suite کامل تازهٔ ۸۵ آزمون موفق روی PostgreSQL جدا |
| مسیر مثبت UI | چهار مورد Chrome/WebKit موفق؛ T25/T17/T19/T12 و IDOR/320px/axe اجرا شدند |
| Firefox | Windows با spawn UNKNOWN اجرا نشد؛ Firefox157 Linux در CI منبع7f403a9 موفق بود |
| dependency/secret | audit تولید صفر advisory؛ تاریخچهٔ فعلی Gitleaks بدون یافته؛ diff نهایی قبل push بررسی می‌شود |
| بررسی مستقل امنیت | ناقص؛ عامل با بازبینی خودکار متوقف شد، گواهی ASVS وجود ندارد |
| image/CI/staging | CI verify منبع7f403a9 موفق (۷۷+۶ مرورگر)؛ تصویر اولیه Grype gate را رد کرد و منتشر نشد؛ پذیرش Linux جایگزین و استقرار هنوز نتیجه ندارند |
| T22 و ظرفیت | encryption round trip و harness موجود؛ restore کامل/۲۰۰ VU هنوز اجرا نشده‌اند |
| live | غیرفعال؛ مالک/کالا/قانون/PSP/SMS/domain/TLS/offsite و آزمون قرارداد/شبکه لازم‌اند |

این جدول تأیید فروش واقعی نیست. محدودیت پیاده‌سازی مستقل با ورودی نامعلوم کسب‌وکار یکی نیست؛ گالری چندگانه و منبع مناطق آماده شده‌اند و پذیرش نهایی آن‌ها، صفحه‌بندی بزرگ و سیاست قابل تنظیم ارسال هنوز جاری‌اند. گزارش وضعیت برای ادامهٔ کار نگه‌داری می‌شود.
