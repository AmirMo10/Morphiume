# شرط‌های انتشار و نتیجهٔ موجود

| شرط | وضعیت مشاهده‌شده |
|---|---|
| مشخصات، نقش‌های واقعی و ده Skill | فاز صفر در b01c09f روی main؛ validator رسمی موفق |
| ساخت یکپارچه، نوع و lint | production build و TypeScript/ESLint موفق؛ اصلاح CSP نیازمند آخرین بازآزمایی |
| مالی/انبار/OTP/MFA | suite کامل ۷۷ آزمون موفق روی PostgreSQL جدا |
| مسیر مثبت UI | چهار مورد Chrome/WebKit موفق؛ T25/T17/T19/T12 و IDOR/320px/axe اجرا شدند |
| Firefox | دانلود موفق، اجرای Windows با spawn UNKNOWN؛ علت نامعلوم؛ CI Linux هنوز نتیجه ندارد |
| dependency/secret | audit تولید صفر advisory؛ تاریخچهٔ فعلی Gitleaks بدون یافته؛ diff نهایی قبل push بررسی می‌شود |
| بررسی مستقل امنیت | ناقص؛ عامل با بازبینی خودکار متوقف شد، گواهی ASVS وجود ندارد |
| image/CI/staging | workflow و runbook آماده؛ نتیجهٔ اجرا/deploy باید ثبت شود |
| T22 و ظرفیت | encryption round trip و harness موجود؛ restore کامل/۲۰۰ VU هنوز اجرا نشده‌اند |
| live | غیرفعال؛ مالک/کالا/قانون/PSP/SMS/domain/TLS/offsite و آزمون قرارداد/شبکه لازم‌اند |

این جدول تأیید فروش واقعی نیست. محدودیت پیاده‌سازی مستقل با ورودی نامعلوم کسب‌وکار یکی نیست؛ تصویر چندگانه، منبع مناطق ارسال و صفحه‌بندی بزرگ هنوز کار مستقل باقی‌مانده‌اند و باید پیش از ادعای تکمیل همهٔ قابلیت‌ها اجرا شوند. گزارش وضعیت برای ادامهٔ کار نگه‌داری می‌شود.
