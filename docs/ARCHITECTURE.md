# معماری اجرایی Morphiume

Next.js 16.4 با TypeScript و PostgreSQL 18.6 یک برنامهٔ ماژولار واحد است. رابط فارسی، API، احراز هویت و تجارت در همان کد نگه‌داری می‌شوند؛ worker مستقل، outbox و تطبیق پرداخت را اجرا می‌کند. Redis، ریزخدمت یا صف خارجی برای این مرحله لازم نشده‌اند.

API در `src/app/api/[...segments]/route.ts` قرارداد عمومی را به هستهٔ تجارت متصل می‌کند. مسیرهای native BetterAuth مشتری و مدیر handlerهای اختصاصی دارند. نشست‌ها cookieهای HttpOnly جدا و secretهای جدا دارند؛ دسترسی مدیر علاوه بر نشست، مجوز MFA زنده و نقش پایگاه داده را بررسی می‌کند. صفحه و API خصوصی no-store هستند. تغییرات نیازمند Origin دقیق محیط جاری‌اند.

مبلغ ورودی مدیر تومان صحیح و مبلغ ذخیره‌شده BIGINT ریال است. شناسهٔ پرداخت، مبلغ، واحد و دریافت مالی توسط سرور تطبیق داده می‌شوند. رزرو موجودی، optimistic version، idempotency و ثبت outbox در تراکنش کوتاه انجام می‌شوند. جزئیات و نمودار داده در مستندات backend ثبت هستند؛ وضعیت مرورگر دلیل موفقیت مالی محسوب نمی‌شود.

رسانهٔ بارگذاری‌شده فقط JPEG/PNG/WebP با حجم و ابعاد محدود پذیرفته می‌شود؛ Sharp تصویر را دوباره کدگذاری و metadata را حذف می‌کند. اصل فایل خصوصی و نسخهٔ WebP عمومی در مسیرهای جدا ذخیره می‌شوند. SVGهای هویت برند فقط دارایی‌های ثابتِ ساخته‌شده در مخزن هستند.

ساخت برنامه به کلید واقعی، DB یا سرویس فروش وابسته نیست؛ اتصال DB و ایجاد instance احراز هویت هنگام اولین عملیات واقعی، تنظیمات را اعتبارسنجی می‌کنند. live فعلاً startup gate صریح دارد؛ ورود mock یا ورودی ناقص مجاز نیست. staging کانتینر، داده، رسانه، secret و backup جدا دارد و از SSH tunnel قابل دسترس است. راهنمای اجرایی و محدودیت منابع در `docs/ops` قرار دارند.
