# ظرفیت و بودجهٔ اندازه‌گیری

سرور مشاهده‌شده چهار CPU، حدود ۴٫۸GiB RAM و چهار GiB swap دارد. این زیر نامزد منابع سند برای ۲۰۰ کاربر است و به‌تنهایی ظرفیت را ثابت نمی‌کند. ساخت/مرورگر روی workstation و CI اجرا می‌شوند؛ generator بار Windows چهار CPU منطقی و ۳۲GiB RAM، جدا از میزبان برنامه است.

سناریوی k6 2.3.0 با آرشیو و SHA رسمی تأیید شده است: افزایش تدریجی تا ۲۰۰ VU، بیست دقیقه پایدار، think time حدود پانزده ثانیه، نسبت سفر ۸۰/۱۰/۸/۲ و آزمون RPS مستقل. `k6 inspect` پیکربندی را واقعاً تأیید کرده، اما هنوز بار به staging برنامه ارسال نشده است. [دستور/fixture و نتیجهٔ واقعی](qa/PERFORMANCE.md) و [محدودیت‌های منابع](ops/CAPACITY.md) مرجع جاری‌اند.

گزارش نهایی باید source/image، dataset، CPU/RAM و اشتراکی/اختصاصی بودن، throughput، p50/p95/p99، خطای تجاری در برابر غیرمنتظره، swap/OOM/restart، pool/locks، صف worker و ledger را ثبت کند. هدف p95 خواندن ۵۰۰ms، checkout داخلی ۱۰۰۰ms و خطای غیرمنتظره زیر ۰٫۵٪، هدف آزمون است؛ تا اجرا ظرفیت ۲۰۰ کاربر ادعا نمی‌شود. نتیجهٔ شبکهٔ SSH و دستگاه واقعی/شبکه‌های ایران نیز باید از نتیجهٔ موتور مرورگر جدا باشد.
