# وابستگی‌ها و مجوزها

DEPENDENCY_LICENSES.json نام، نسخهٔ نصب‌شده، کاربرد توسعه/اجرا، مجوز اعلامی ناشر، مخزن و hash metadata وابستگی‌های مستقیم را ثبت می‌کند. با `node scripts/dependency-licenses.mjs` پس از نصب frozen lockfile بازتولید می‌شود و ناسازگاری با نسخهٔ pin را رد می‌کند. وابستگی‌های گذرا و سیستم‌عامل باید از SBOM همان تصویر پذیرفته‌شده بررسی شوند؛ تا پذیرش تصویر، SBOM نهایی منتشرشده ادعا نمی‌شود.

گالری، فونت و دادهٔ مناطق ثبت مجوز جدا دارند. بستهٔ native Sharp/libvips و متن مجوزهای همراه همان platform در خروجی اجرایی نگه‌داری می‌شوند. ثبت metadata و موفقیت اسکن آسیب‌پذیری، گواهی انطباق حقوقی یا جایگزین بررسی تعهدهای هر مجوز نیستند.
