# ورود مالک به پنل آزمایشی

بازبینی تحویل ۱۸ اکتبر ۲۰۲۶: نسخهٔ بازطراحی‌شده روی همان IP خصوصی پذیرفته شد؛ اطلاعات ورود قبلی حفظ شده‌اند و حساب مالک در آزمون‌های تازه استفاده یا بازنشانی نشد. [وضعیت جاری](../STATUS.md) و [شواهد استقرار](REDESIGN_STAGING_EXECUTION.md). فایل مالک فقط برای Admin و SYSTEM قابل دسترسی است و مجوزهای مؤثرش از والدِ محافظت‌شده می‌آیند؛ فایل دسترسی preview مجوز صریحِ محافظت‌شده دارد. این مشاهدهٔ محلی رمز یا مجوزی را تغییر نداد. نخستین ورود و ثبت MFA همچنان باید توسط خود مالک انجام شود.

حساب شخصی مالک با ایمیل ارائه‌شدهٔ خود او، در ۱۳ اکتبر ۲۰۲۶ ساعت ۱۲:۳۷:۳۸٫۹۶۳ UTC روی پایگاه staging جاری ساخته شد. فقط یک user، یک credential account و یک role_membership با نقش owner اضافه شدند. حساب موجود دیگری تغییر نکرد؛ ۲۳۵ ردیف قبلی احراز هویت و همهٔ ۴۶۹۴ ردیف مالی خوانده‌شده در ۱۴ جدول حفظ شدند. دادهٔ کالا یا نمونهٔ تازه ساخته نشد.

رمز از ۳۲ بایت تصادفی مستقل ساخته و با هش BetterAuth ذخیره‌شده تطبیق داده شد. اطلاعات حفاظت HTTP و ایمیل/رمز پنل فقط در فایل محلی `.local/Morphiume-owner-access.txt` قرار دارند؛ این فایل و شواهد خصوصی ignored هستند و ACL فقط Admin جاری و SYSTEM را مجاز می‌کند. این سند و Git فاقد رمز، ایمیل و شناسهٔ شخصی مالک‌اند.

برای ورود، [صفحهٔ مدیریت](http://192.168.240.51/admin/login) را از شبکهٔ مجاز باز کنید. نخست اطلاعات حفاظت HTTP را از فایل محلی وارد کنید؛ سپس در فرم پنل، ایمیل و رمز شخصی همان فایل را وارد کنید. «ساخت کلید رمزساز» را انتخاب، کلید را در برنامهٔ رمزساز خود ثبت و کد شش‌رقمی را تأیید کنید. کدهای بازیابی را در جای امن نگه دارید.

ورود با رمز همین حساب روی سرور در ۱۲:۴۶:۳۷٫۲۶۷ تا ۱۲:۴۶:۳۸٫۰۱۸ UTC واقعاً بررسی شد: sign-in و session هر دو ۲۰۰، دسترسی feed مدیریتی پیش از MFA برابر ۴۰۳، و sign-out برابر ۲۰۰ بود. مجوز پیش از MFA صفر بود و نشست دقیق آزمون پس از خروج باقی نماند. این بررسی هیچ MFA یا admin grant نساخت و تغییری در دادهٔ مالی نداد.

نخستین ورود و تنظیم MFA توسط خود مالک هنوز اجرا نشده‌اند؛ تأیید بیرونی تحویل ایمیل نیز انجام نشده است. نقش owner به‌تنهایی MFA اجباری برنامه را دور نمی‌زند. این حساب برای محیط آزمایشی فعلی است؛ درگاه و پیامک کنترل‌شده‌اند و فروش واقعی فعال نیست.
