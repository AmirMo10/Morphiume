## Producer and contents

`browser-toolchain.yml` is a separate Ubuntu24.04 job triggered only by main changes to that workflow, its export script or its dedicated Node contract test. It checks out the exact event commit using the existing pinned checkout action with persisted credentials disabled; Node24.21.0, pnpm11.25.0 and the frozen lockfile select Playwright1.64.0. A fresh explicit cache directory receives only the maintained command `playwright install --with-deps chromium firefox webkit`. There is no database, `.env` generation, SSH, application/browser-test session, private profile or native fixture. The job does not start Docker.

The exporter requires Linux/x64/Ubuntu24.04/Node24.21.0, exact checked-out source40hex, declared package-manager/Playwright pins and installed core1.64.0. Browser directory revisions come from that pinned `browsers.json`, including the pinned registry's exact `name_hostPlatform_special` directory prefix and omission of the default browserVersion when overridden. Current Ubuntu24.04 has no override. Chromium,Firefox,WebKit are required; only the registry's exact ffmpeg/headless-shell directories may additionally appear. Unknown top-level cache entries fail. The installer `.links` directory is excluded because it contains source-location pointers; a symlink named `.links` fails, and its contents are never read/exported.

All distribution files, resources and license notices inside accepted official engine directories are retained and enumerated. The trusted fresh official download job establishes their provenance; filename validation alone does not independently authenticate browser binaries. The exporter rejects secret/profile canary paths, hidden members, traversal, control characters, special files, hardlinks, duplicate members, absent/non-directory parents, group/other-writable regular files/directories and setuid/setgid modes. Relative symlinks must resolve to a listed member within the same engine; absolute, dangling, cyclic and cross-engine links fail. It never follows a cache symlink to hash an outside file.

Bounds:50000 members,4GiB total regular-file bytes,1GiB per file,1024 UTF-8 bytes per path/target,32 path segments. File size/count/aggregate bounds apply during collection before hashing excessive data. Each file is SHA256-hashed, with inode/mtime/size stability checked; a full second cache scan after archiving must match. Licenses are included and listed. The tar retains validated Unix permissions/relative links, normalizes owner/group to numeric0 and timestamps to0, and omits filesystem identities and atime/ctime metadata. This archive normalization does not change any host or native-auth clock.

Only three explicit files are uploaded, with artifact compression disabled for the already compressed tar:

- `browser-toolchain-ubuntu24.04-x64-playwright1.64.0.tar.gz`: browser cache payload only.
- `browser-toolchain.manifest.json`: schema1, sourceCommit, exact platform/versions, lockfile/exporter SHA256, archive filename/size/SHA256, engine revisions/versions, counts, excluded-registry-links flag, license-file list and every member's relative filename/type/mode/bytes/fileSHA256 or link target.
- `browser-toolchain.sha256`: archive SHA256 sidecar.

The private member-list helper file, node_modules, source tree, `.local`, raw logs, environment, tokens, users and profile data are not uploaded. GitHub's upload action separately outputs the artifact ZIP digest; an artifact cannot contain its own final ZIP digest without circularity. [The pinned upload-artifact interface](https://github.com/actions/upload-artifact/blob/ea165f8d65b6e75b540449e92b4886f43607fa02/README.md#outputs) defines `artifact-digest` asSHA256. [Official Playwright browser installation](https://playwright.dev/docs/browsers) couples binary revisions to Playwright and documents `install --with-deps`.
