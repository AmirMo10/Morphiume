# مجوزهای اجراشده

منبع واحد مجوز در `src/server/commerce/permissions.ts` است. هر API خصوصی علاوه بر نشست معتبر، وضعیت فعال کاربر و نقش فعلی DB را دوباره بررسی می‌کند. همهٔ عملیات مدیریت MFA لازم دارند؛ تغییر نقش و تکمیل بازپرداخت، تأیید عامل دوم در پنج دقیقهٔ اخیر نیز لازم دارند.

| نقش | عملیات مجاز |
|---|---|
| مالک | کاتالوگ، انبار، سفارش، ارسال، بازپرداخت، نقش و محتوا |
| مدیر محصول | کاتالوگ و محتوا؛ افزایش موجودی اولیه بدون مجوز انبار مجاز نیست |
| انبار/ارسال | موجودی، اطلاعات لازم سفارش و ثبت ارسال/تحویل؛ مبلغ‌ها و جزئیات بازپرداخت از پاسخ API حذف می‌شوند |
| پشتیبان | مشاهدهٔ سفارش و یادداشت داخلی؛ بازپرداخت و تغییر نقش مجاز نیست |
| مالی | مشاهدهٔ سفارش، دریافت‌های مالی و گردش بازپرداخت؛ تغییر نقش و موجودی مجاز نیست |
| مشتری | فقط سفارش، نشانی و علاقه‌مندی خود؛ checkout پس از OTP معتبر |

cookieهای مشتری و مدیر مستقل‌اند. مدیرِ صرفاً واردشده با رمز هنوز مجوز داده‌های پنل ندارد و فقط مسیر تکمیل MFA را می‌بیند. نقش یا نشست لغوشده در درخواست حساس بعدی پذیرفته نمی‌شود. آخرین مالک فعال با lock تراکنشی محافظت می‌شود. ماتریس HTTP کامل و بررسی مستقل ASVS هنوز نتیجهٔ کامل ندارد؛ موارد واقعاً آزموده‌شده در گزارش QA آمده‌اند.
